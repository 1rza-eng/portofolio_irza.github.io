IRZA — PERSONAL PORTFOLIO
=========================
Cara pakai:
1. Ekstrak ZIP. Buka folder irza-portfolio di VS Code.
2. Buka index.html di browser, atau gunakan Live Server.
3. Untuk hosting, upload semua isi folder (index.html, style.css,
   script.js, assets/) ke direktori web, misalnya public_html.
   Tidak membutuhkan PHP, database, Node.js, atau library eksternal.
4. GitHub Pages: upload isi folder ini ke root repository (bukan ZIP).
   Settings > Pages > Deploy from a branch > main > / (root) > Save.

File:
- index.html: struktur dan isi halaman.
- style.css: desain, responsive layout, animasi CSS.
- script.js: menu mobile, scrollspy, parallax, reveal, lightbox.
- assets/images/: foto dan preview asli yang diekstrak dari PDF.
- assets/CV-Irza.pdf: CV asli dari user (tombol Download CV).

Yang perlu disesuaikan sebelum publish:
- CV: tombol Download CV sudah mengunduh CV asli. Untuk memperbarui CV,
  ganti assets/CV-Irza.pdf dengan file baru bernama sama.
- LinkedIn: PDF berisi nama, bukan URL profil. Ganti kedua URL pencarian
  LinkedIn dengan URL profil yang benar.
- GitHub: link berdasarkan username PDF. Link project menuju profil karena
  URL repository masing-masing tidak tercantum; ganti jika repository publik tersedia.
- Instagram, WhatsApp, GitHub: konfirmasi akun/nomor masih aktif sebelum publish.
- Sertifikat: preview berasal dari PDF, bukan file sertifikat resolusi asli.
  Ganti gambar jika punya file asli. Pastikan informasi sertifikat boleh dipublikasikan.
- Kontak: email dan nomor WhatsApp dari PDF ditampilkan secara publik.
  Hapus atau ganti bila tidak ingin menampilkannya.

Desain: single-page yang mengadaptasi 7 halaman PDF; warna broken white,
serif editorial, Home/Contact gelap. Font sistem, tanpa ketergantungan CDN.
Animasi mendukung prefers-reduced-motion. Semua konten utama tetap bisa
terbaca ketika JavaScript dinonaktifkan (navigasi mobile memerlukan JS).
